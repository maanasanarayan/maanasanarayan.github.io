## 2. Information We Collect

This website does **not** use tracking cookies, invasive advertising scripts, fingerprinting, or cross-site tracking mechanisms. When you access the website, standard web server access logs may temporarily record:

- The IP address from which the request was made
- Date and time of the request
- HTTP request method, requested URL, and response status code

- Referrer URL (if provided by your browser)

This information is processed automatically by our hosting infrastructure solely to serve website assets, protect against malicious traffic or denial-of-service attempts, and ensure network security.
